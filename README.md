# DescoTech Servicios

Portal independiente de DescoTech para presentar servicios, generar cotizaciones aproximadas, agendar revisiones y dar seguimiento a solicitudes.

## Vistas

- `index.html`: página pública, chat, agenda, cotizador y cuenta local de demostración.
- El panel administrativo se conserva en un repositorio privado independiente y no forma parte de esta publicación.

## Estado actual

La versión actual es una demostración estática. Las cuentas y solicitudes se guardan únicamente en el navegador mediante `localStorage`. Antes de usarla con clientes reales se requiere autenticación, base de datos y recuperación de contraseña mediante un servicio seguro.
